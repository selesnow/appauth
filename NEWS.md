# appauth 0.0.0.9000

* Каркас пакета: структура папок, `DESCRIPTION`, лицензия, `.gitlab-ci.yml` с установкой в общую библиотеку сервера и уведомлениями в Telegram.
* Добавлена виньетка `architecture-and-security`: модель угроз, состав системы и данные, потоки (вход, первый запуск, автовход, выход, проверка прав, управление пользователями, старт приложения), гарантии, принятые решения и причины, известные ограничения, ответственность приложения, уроки найденных ошибок.
* Добавлены настройки и тексты:
    * `aa_settings()` - настройки авторизации (защита от подбора пароля, правила пароля, автовход, сроки хранения данных, роли), значения по умолчанию как в Server Manager;
    * `aa_settings_from_list()` - настройки из списка, например из раздела `config.yaml`;
    * `aa_texts()` - тексты интерфейса и сообщений на русском и английском с возможностью заменить любую строку, `aa_text()` - получить текст по ключу с подстановкой значений, `aa_text_keys()` - список ключей.
* Добавлена схема базы данных SQLite с версионными миграциями:
    * `aa_init_db()` - создать или достроить таблицы `users`, `auth_sessions`, `login_attempts` и служебную `appauth_migrations`, существующие данные не изменяются, повторный запуск ничего не меняет, распознаются старые схемы (в том числе таблица `users` без `id` и без `blocked`, пароли в открытом виде);
    * `aa_schema_version()` - версия схемы;
    * `aa_cleanup()` - удалить устаревшие попытки входа и токены;
    * `aa_prepare_db()` - подготовка базы при запуске приложения, которая не останавливает приложение при ошибке.
* Добавлена работа с паролями:
    * `aa_hash_password()` - хеш scrypt (пакет `sodium`) для хранения в базе, `aa_verify_password()` - проверка пароля по хешу (пароли в открытом виде, повреждённые хеши и сам хеш в качестве пароля никогда не проходят проверку, ошибок функция не бросает), `aa_is_password_hash()` - отличить хеш от открытого пароля;
    * `aa_validate_password()` и `aa_validate_login()` - проверка нового пароля и логина по правилам из `aa_settings()` (длина считается в символах), тексты ошибок на языке настроек;
    * `aa_migrate_plaintext_passwords()` - разовый перенос паролей из открытого вида в хеши с резервной копией, транзакцией, проверкой каждого хеша по исходному паролю и режимом `dry_run`, повторный запуск безопасен;
    * `aa_check_default_accounts()` и `aa_common_passwords()` - поиск учётных записей с паролем в открытом виде, паролем, совпадающим с логином, или распространённым слабым паролем.
* Совместимость схемы проверена на копиях баз Server Manager (dev и prod): данные всех таблиц не изменяются, добавляется только служебная таблица `appauth_migrations`.
* Добавлены автотесты (`tests/testthat`): настройки, тексты, схема и миграции, в том числе на фикстурах старых схем Server Manager и приложения рекрутинга.
