
# appauth

<!-- badges: start -->
<!-- badges: end -->

Пакет `appauth` содержит безопасную авторизацию и управление пользователями для Shiny приложений нашего отдела. Он создан на основе авторизации приложения Server Manager и должен заменить самописный код входа, паролей и сессий в наших приложениях.

**Статус: пакет в разработке (версия 0.0.0.9000), функций пока нет.** План работ: сначала документ об архитектуре, затем вынос ядра (пароли, защита входа, блокировки, сессии, права), затем модули интерфейса.

## Что будет делать пакет

* Хранение паролей только в виде хешей (scrypt), открытые пароли не принимаются.
* Вход по логину и паролю, автовход по cookie, выход и принудительный выход заблокированных и удалённых пользователей.
* Защита от подбора пароля: блокировка логина после неудачных попыток и общий лимит по всем логинам.
* Ручная блокировка пользователей, защита от удаления себя и последнего активного администратора.
* Серверные проверки прав, а не только скрытие кнопок в интерфейсе.
* Модуль входа с окном создания первого администратора и модуль управления пользователями с точками расширения для своих блоков.
* Версионные миграции схемы базы данных SQLite, совместимые с базами Server Manager.

## Настройка и установка

Пакет установлен в общую библиотеку пакетов на сервере и при каждом обновлении автоматически обновляется в ней, поэтому никакой дополнительной настройки не требует.

## Принципы

* Пакет содержит только то, что должно быть одинаковым во всех приложениях (безопасность), всё остальное (матрица ролей и прав, переключатели логов, состав вкладки доступа) остаётся за приложением и описывается в навыках разработки.
* Пакет работает с SQLite, подключение передаётся из приложения.
