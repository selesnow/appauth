# List of common weak passwords

Used by
[`aa_check_default_accounts()`](https://alexey-seleznev.pro/appauth/reference/aa_check_default_accounts.md)
by default.

## Usage

``` r
aa_common_passwords()
```

## Value

A character vector.

## Examples

``` r
head(aa_common_passwords())
#> [1] "root"          "admin"         "administrator" "password"     
#> [5] "passw0rd"      "pass"         
```
